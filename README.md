# Viphou's Developer Portfolio

A profile page built with Vite + React to practice core JSX rules: single parent element, `className`, closed tags, and live expressions in curly braces. Includes a `StatusBadge` component that uses a ternary to switch between "Open to work" and "Busy learning".

## Setup

```bash
npm install
npm run dev
```

Then open the printed local URL (e.g. `http://localhost:5173`) in your browser.
